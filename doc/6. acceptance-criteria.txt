--------------------------------------------------------------------

-Display an input request from the system 
-Show an error message in case of input sentence with no letters (ask again for the input sentence)
-Display the input sentence 

---------------------------------------------------------------------

USER STORY 2: The system shall analyze the input sentence (?)

-Show a validation error if the input sentence structure isn't acceptable(?) and eventually start from USER STORY 1

---------------------------------------------------------------------

USER STORY 3: The system shall generate a correct sentence template

-Display the generated template (showing where different type of words need to be inserted)

--------------------------------------------------------------------

USER STORY 4: The system shall select additional terms to fill the template

-Display the words extracted from the built-in dictionary divided in lists each labeled with a word type

--------------------------------------------------------------------

USER STORY 5: The system shall generate a new sentence by filling the generated template with the selected terms

-Acceptance criteria in USER STORY 6,7 

--------------------------------------------------------------------
